# Python Activity-Based Learning

A 10-case-study academic project implementing the assigned introductory Python syllabus:
variables, data types, operators, conditional statements, loops, strings, pattern generation,
lists, nested lists, tuples, tuple operations, and tuple unpacking.

## Selected Case Studies

1. Employee Payroll and Deduction Analysis
2. Retail Billing with Multiple Discount Rules
3. Attendance Recovery Computation
4. Warehouse Inventory Reconciliation
5. Student Performance Trend Analysis
6. Student Timetable Conflict Detection
7. Repeated Transaction Detection
8. Nested Loop Calendar Generator
9. Student Marks Matrix Analysis
10. Smart Canteen Order and Stock Management

## Project Structure

```text
Python-Activity-Based-Learning/
|-- README.md
|-- requirements.txt
|-- programs/       # Ten standalone Python programs
|-- docs/           # Algorithms, pseudocode, flowcharts, and test cases
|-- outputs/        # Captured terminal output
|-- screenshots/    # Terminal screenshots
|-- report/         # Complete assignment PDF
```

## Requirements

- Python 3.8 or newer
- No third-party package is required to execute the programs

## Run

```powershell
python programs/case_01_employee_payroll.py
python programs/case_02_retail_billing.py
python programs/case_03_attendance_recovery.py
python programs/case_04_warehouse_inventory.py
python programs/case_05_student_performance.py
python programs/case_06_timetable_conflicts.py
python programs/case_07_transaction_detection.py
python programs/case_08_calendar_generator.py

```

## Learning Outcomes

- Decompose real-world problems into algorithms and pseudocode
- Use appropriate conditional and iterative control structures
- Represent data with strings, lists, nested lists, and tuples
- Produce validated calculations and readable reports
- Test normal and boundary conditions
